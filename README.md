# DNA-Forensics-v5

Requirements:  
Django, MinIo SDK  

Major Update  
UI and report generation modification.  

To run go to the directory of manage.py.  
Then run the following:  
venv\Scripts\activate.bat -------- in command prompt to activate virtual environment.  
python manage.py runserver -------- to run django server.  

Go to MinIO folder and execute the following to run minio server.  
.\minio.exe server D:\minio\data --console-address ":9090"
